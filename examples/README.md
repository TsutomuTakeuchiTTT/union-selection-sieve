# Worked example

`sample_catalog.csv` is a small simulated Region-A--C catalogue generated under the same bounded-Gaussian and seven-threshold design used in the paper. It is intended only to demonstrate file format and execution.

Run

```bash
union-selection-fit --input examples/sample_catalog.csv --outdir outputs/example_fit --bins 8
```

or execute `notebooks/quickstart.ipynb`.
